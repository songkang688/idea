# Idea_02 — PromptAmnesia (Windows4, Stage 7 package)

**One sentence (HYPOTHESIS):** Fine-tuning a promptable segmenter erodes zero-shot interactive skills
non-uniformly by prompt type — an ordering that survives a mixed-prompt fine-tuning distribution (so it is
forgetting, not coverage), exceeds the threshold/seed/prompt-sampling noise floor, includes genuine loss of
multimask ambiguity capability (oracle best-of-3, not just IoU-head ranking), and localizes causally under
stitch-controlled module splicing.

- **Papers bundled:** P065 (C1-065 + C1-061, flagship) · P082 (C1-082 + S-183, gate — **runs first**) ·
  P177 (S-177 + C1-062, mechanism arm — **stitching controls mandatory**).
- **Stage-4 verdicts inherited:** all three WEAK ACCEPT, conditional; P110 REJECT → reporting-panel
  appendix; P108 REJECT → drift logged as free covariate. See `selection_history/stage4_r2_setB.md`.
- **Stage-6 lock:** `selection_history/stage6_battle.md` — Idea_02 of the final 3.

**Epistemic status of the whole package:** PROPOSAL. **No experiments have been run; no metric anywhere in
this directory is a measurement.** Numbers are design parameters, pre-registered thresholds, or compute
ESTIMATES. Result files generated by the prototype in `--dry-run` mode contain NaN placeholders by design.

## Binding obligations (contract — dropping any reverts Stage-4 verdicts to REJECT)

1. **Mixed-prompt FT column** licenses every forgetting claim; box-only column is only the coverage map.
2. **Oracle best-of-3 vs argmax decomposition** carries the diversity claim; ranking-loss outcomes
   transfer to sibling P031.
3. **P177 stitching controls**: trained affine stitches, both swap directions, stitch-only calibration
   cells, per-module α-interpolation, update-norm accounting.
4. **P082 runs first**: symmetric threshold protocol, released checkpoints only for named indictments,
   pre-registered target list, envelope gate decides PROCEED vs PIVOT.
5. Grid recipe + matched-gain rule pre-registered once, frozen before any analysis (tag
   `idea02-prereg-v1`).
